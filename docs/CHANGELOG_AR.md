# سجل التغييرات

## 3.2.0 — ثبات وتشخيص وأيقونة
- إضافة أيقونة Android تكيفية باسم نواة Studio.
- إضافة سجل محلي لآخر انهيار غير معالج، مع نافذة في التشغيل التالي لنسخ تقرير التشخيص.
- حماية تهيئة قائمة ملفات المشروع ومحلل NawaScript من أخطاء الاستثناءات كي لا يؤدي خطأ تحليل واحد إلى إغلاق التطبيق مباشرة.
- هذه النسخة تجمع التشخيص؛ سبب الانهيار السابق لا يُعد مؤكدًا قبل قراءة تقرير الجهاز.
