# سجل التحقق — نواة NAWA Studio 3.1.0

## ما اختُبر محليًا

- في هذه الجولة، جُمّعت وحدات Kotlin الأساسية المستقلة عن Android باستخدام `kotlinc` بنجاح. اجتاز اختبار دخان للتحقق من العناصر الأربعة، وإحداثيات النص/الأزرار، وتحريك عنصر عبر محرر المصدر، ورفض عدم تطابق النوع ونطاق المنزلق غير الصالح، وتوليد Compose بما فيه التمرير الأفقي والرأسي والارتفاع الديناميكي.
- سجل النسخة السابقة 3.0.0 كان يوثّق **52 اختبار مكوّن ناجحًا و0 فشل** عبر محمّل JVM خفيف، لا عبر مهمة Gradle/JUnit الرسمية. لم تُعَد هذه الاختبارات الـ52 في جولة 3.1.0 الحالية، لذلك لا أعدّها نتيجة جديدة لهذا الإصدار.
- تغطي الاختبارات قواعد الشروط والأوامر والحلقات وحدودها، والعمليات الحسابية، والتنقل، والدوال المحلية، والتنسيق وإعادة ترتيب المصدر، وإعدادات Android، وتوليد مصدر المشروع، وسجل النسخ، وفحص المشروع.
- تحقق فحص ساكن لمصادر المشروع من سلامة JSON وقواعد TextMate وXML الخاصة بالمشروع.
- اجتاز فحص تكامل منفصل لمستودع المشروع (باستخدام `Context` و`JSONObject` تجريبيين خارج التطبيق): إنشاء مشروع، التأكد من وجود ملفات ومجلدات scaffold، وتصدير/استيراد حزمة تحفظ المجلدات الفارغة، والتحقق من القوالب الخمسة وتصدير مشروع Android لكل منها. هذا الاختبار لا يمثّل تشغيل Android حقيقيًا.

## ما لم يتم التحقق منه

- لا يتوفر Gradle أو Android SDK/Build Tools في بيئة إعداد هذا الأرشيف، وتعذّر الوصول إلى مستودعات تنزيل الأدوات. لذلك لم يتم تنفيذ `testDebugUnitTest assembleDebug` بواسطة Gradle، ولم ينتج APK هنا.
- لم يتم تجميع `MainActivity.kt` بواسطة Android Gradle Plugin، ولم يتم تثبيت التطبيق أو اختباره على جهاز Android فعلي. نجاح تجميع وحدات Kotlin المنفصلة لا يضمن خلو تطبيق Compose الكامل من كل أخطاء التكامل.
- لم يتم تشغيل جميع القواعد اللغوية أو التلوين على كل أنواع الملفات. وجود ملف grammar أو تلوين نصي ليس Language Server متكاملًا.
- تم فحص حفظ المجلدات الفارغة في اختبار تكامل JVM بمستودع تجريبي، لكنه لم يخضع لاختبار Android/Gradle فعلي بسبب غياب البيئة؛ يجب تشغيل اختبارات Gradle بعد استنساخ المشروع.

## الحدود الوظيفية

- NawaScript لغة صغيرة: حالات `Int` و`String` و`Bool`، ونصوص وأزرار وأربعة ضوابط مرتبطة بالحالة، وشاشات وتنقل، وشروط محدودة، وعمليات حسابية صحيحة، و`repeat` و`while` محدودة إلى 1000 تكرار، ودوال إجراءات محلية بلا معاملات أو قيم راجعة.
- المصمم يدعم نقل عناصره بالضغط المطوّل في الاتجاهين، ويخزن المواضع في المصدر ويعرض ويولد ضوابط أساسية. لكنه لا يدعم كل مكونات Android ولا قيود التصميم المرن والاستجابي كاملة.
- محرر Kotlin/Java يتيح تحرير النص والتلوين، لكنه لا يقدم بعد تحليلًا دلاليًا وإعادة هيكلة وتصحيحًا كاملًا.
- مولّد Android يجهّز مصدر Gradle/Compose من التركيبات المدعومة ويضمّن المصادر الأصلية المحددة. لا يبني APK داخل تطبيق نواة نفسه، ولا يستطيع ضمان صحة كود Kotlin/Java المستخدم.
- مجلد `plugins/` الحالي نقطة تنظيم لوصف الإضافات، وليس نظام تحميل وتشغيل/توقيع/توزيع إضافات جاهزًا.

## شرط إعلان اكتمال التطبيق

يُعتبر APK قابلًا للتسليم بعد نجاح بناء Gradle الفعلي، والتحقق من الملف والتوقيع، ثم تثبيت التطبيق وتشغيل اختبارات واجهته على Android. إعداد GitHub Actions موجود لهذا الغرض لكن نجاحه لم يُرصد من بيئة إعداد الحزمة.
