# دليل NawaScript — نواة NAWA Studio 3.1.0

NawaScript لغة تجريبية صغيرة مضمّنة في نواة. المحلّل يبني شجرة إجراءات محددة النوع؛ لا تستخدم اللغة `eval` ولا تشغّل كودًا اعتباطيًا. الأمثلة أدناه توضح النطاق الحالي، ولا تعني دعم صياغة Kotlin أو أي لغة أخرى.

## مثال متعدد الشاشات

```nawa
app "عداد" {
    screen Home {
        state count: Int = 0
        state message: String = "أهلاً بك في نواة"
        state enabled: Bool = true

        text("{message}").at(16, 18)
        text("العدد الحالي: {count}").at(16, 60)

        button("زيادة") { count = count + 1 }.at(16, 112)
        button("تغيير الرسالة") { message = "تم الضغط" }
        button("ضعف العدد") { count = count * 2 }

        button("زيادة حتى 10") {
            while (count < 10 && enabled) {
                count = count + 1
            }
        }

        button("زيادة آمنة") {
            if (count < 10 && enabled) {
                count = count + 1
                message = "تمت الزيادة"
            } else {
                message = "لم تتغير القيمة"
            }
        }

        button("إضافة ثلاثة") {
            repeat(3) { count = count + 1 }
        }

        fun resetCount() { count = 0 }
        button("تصفير") { resetCount() }
        button("الإعدادات") { navigate("Settings") }
        input("اكتب اسمك", message).at(16, 176)
        switch("التفعيل", enabled).at(16, 232)
        checkbox("تذكر الاختيار", enabled).at(16, 286)
        slider("الحجم", count, 0, 100).at(16, 340)
    }

    screen Settings {
        state darkMode: Bool = false
        text("الإعدادات")
        button("تبديل المظهر") { darkMode = !darkMode }
        button("رجوع للرئيسية") { navigate("Home") }
    }
}
```

## القواعد المدعومة

- `app "Name" { ... }`، و`screen ScreenName { ... }` لعدة شاشات بأسماء فريدة.
- حالات الشاشة: `Int` و`String` و`Bool`/`Boolean` مع قيم أولية صحيحة النوع.
- واجهة المستخدم: `text("...")` و`button("...") { ... }`. تُعرض الحالة داخل نص بصيغة `{stateName}`.
- عناصر إدخال أصلية مرتبطة بحالة الشاشة: `input("Placeholder", stringState)` للنص، و`switch("Label", boolState)` و`checkbox("Label", boolState)` للقيم المنطقية، و`slider("Label", intState, min, max)` للأعداد الصحيحة. يلزم تطابق نوع الحالة مع عنصر الإدخال.
- مواضع مطلقة اختيارية بالنقاط المستقلة عن كثافة الشاشة (dp): أضف `.at(x, y)` بعد العنصر، مثل `text("عنوان").at(20, 36)`. تُستخدم المواضع في المصمم المحلي والمعاينة ومصدر Jetpack Compose المُولّد. إذا لم يوجد أي موضع في الشاشة، تبقى الواجهة في تخطيط عمودي تقليدي؛ وعند استخدام موضع واحد تتحول الشاشة إلى مساحة تصميم مطلقة، وتُرتّب العناصر غير المزودة بموضع افتراضيًا أسفل بعضها. النطاق المدعوم X من 0 إلى 2048 وY من 0 إلى 4096.
- التنقل: `navigate("ScreenName")`، مع فحص وجود شاشة الهدف.
- إسناد الأعداد والنصوص والقيم المنطقية، والزيادة والنقصان، والعمليات الحسابية مع ثابت صحيح: `*` و`/` و`%`. القسمة أو باقي القسمة على صفر مرفوضان؛ نتائج التجاوز العددي لا تُقبل في التنفيذ.
- الشروط: `if (...) { ... } else { ... }`، ومقارنات `==`, `!=`, `<`, `<=`, `>`, `>=`، والمنطق `&&`, `||`, `!` ضمن الأنواع المدعومة.
- `repeat(n) { ... }` عندما يكون العدد ثابتًا من 0 إلى 1000.
- `while(condition) { ... }` بحد أمان 1000 تكرار. إذا بقي الشرط صحيحًا بعد الحد، يتوقف التنفيذ/التوليد بدل السماح بحلقة غير محدودة.
- `fun name() { ... }` كإجراء محلي للشاشة بلا معاملات أو قيمة راجعة؛ ترفض الاستدعاءات الدائرية.
- تسلسل عدة إجراءات داخل الأزرار، مع أقواس ومقاطع متداخلة ضمن حدود المحلّل.

## حدود اللغة

ليست لغة عامة بعد: لا توجد معاملات أو قيم راجعة للدوال، أو مكتبات NawaScript، أو مصفوفات وكائنات وأنواع مركّبة، أو استدعاءات خارجية عامة، أو `for`، أو async/threads. عناصر UI المتاحة هي النص، والأزرار، وحقل النص، والمفتاح، ومربع الاختيار، وشريط الأعداد. لا تتضمن اللغة نظام أنواع كاملًا كـ Kotlin، ولا يمكنها تشغيل ملفات Kotlin/Java التي تفتح في المحرر. التخطيط المطلق بسيط ولا يضاهي محرر قيود احترافيًا أو Android Studio Layout Inspector.

## مشروع المصدر

يستخدم المشروع `project.nawa` للبيانات الوصفية، و`src/main.nawa` لمدخل اللغة، و`android.properties` لإعدادات التصدير. الحزمة `.nsqpack` هي ZIP مع فحص للمسارات والأحجام وعدد العناصر، بما في ذلك استعادة المجلدات الفارغة.
